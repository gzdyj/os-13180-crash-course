第1章 操作系统概述

  • 操作系统定义：管理计算机软硬件资源、控制程序执行、方便用户使用的系统软件。
  • 四大功能：处理机管理、存储管理、设备管理、文件管理。
  • 四大特征：并发、共享、虚拟、异步。⚠️ 最常考：并发与共享是最基本的两个特征，互为存在条件。
  • 发展历程：手工 → 批处理（单道/多道）→ 分时 → 实时。多道程序设计：内存中同时存放多道程序，宏观并行、微观串行。
  • 分时系统特点：多路性、独立性、及时性、交互性；实时系统：可靠性优先。
  • 常见题型：选择题判断"哪个不是 OS 特征/功能"；分时 vs 实时辨析。

第2章 进程管理（分值大户 ⭐⭐⭐）

进程与线程

  • 进程：程序的一次执行过程，是资源分配的基本单位；线程：CPU 调度的基本单位。
  • 进程组成：PCB（进程控制块）+ 程序段 + 数据段。PCB 是进程存在的唯一标志。
  • 三种基本状态：就绪、运行、阻塞（等待）。运行→阻塞是"主动"（等I/O等事件）；阻塞→就绪是"被动"（事件发生被唤醒）。⚠️ 阻塞不能直接变运行。

PV 操作（信号量机制）——必考

P 操作（wait）：S = S − 1；若 S < 0，进程阻塞入等待队列
V 操作（signal）：S = S + 1；若 S ≤ 0，唤醒一个等待进程
  • 互斥：信号量初值 = 1（互斥信号量 mutex）；同步：初值 = 资源数量。
  • PV 必须成对出现；判断题常考"P 在前 V 在后顺序可随意"——错，顺序错误可能死锁。

死锁

  • 四个必要条件（缺一不可，必背）：互斥、占有且等待（请求和保持）、不可剥夺（不可抢占）、循环等待。
  • 处理策略：预防（破坏四条件之一）、避免（银行家算法）、检测与解除。
  • 银行家算法思路：找到"安全序列"则安全；找不到安全序列则拒绝分配（可能死锁）。考计算题：给分配表，判断状态是否安全。

调度算法

算法规则特点/考点
FCFS 先来先服务按到达顺序公平，但对短作业不利
SJF 短作业优先最短的先平均等待时间最短；可能饿死长作业
RR 时间片轮转按时间片轮流分时系统常用；时间片太大→退化为FCFS，太小→切换开销大
优先级调度优先级高的先静态/动态；可能饿死低优先级
多级反馈队列多个队列时间片递增兼顾各方面，最灵活

第3章 内存管理（计算题重灾区 ⭐⭐⭐）

基本概念

  • 逻辑地址（虚拟）vs 物理地址；地址重定位：静态（装入时）/ 动态（运行时）。
  • 交换与覆盖：扩充内存的早期手段。

连续分配

  • 分区：首次适应、最佳适应（产生大量小碎片）、最坏适应。
  • 碎片：内部碎片（分区内浪费）vs 外部碎片（分区之间小空间）。

分页（重点计算！）

物理地址 = 块号（页框号）× 页大小 + 页内偏移
页号 = 逻辑地址 ÷ 页大小（取整）　偏移 = 逻辑地址 mod 页大小
  • 页表：页号→块号的映射。每进程一张。
  • 页面大小通常 4KB；逻辑地址 32 位可分页号位数 + 偏移位数。

虚拟存储与页面置换算法（必考计算）

算法规则考点
OPT 最佳置换淘汰以后最久不用的页理论最优，无法实现（需未来信息），做题基准
FIFO 先进先出淘汰最先进入内存的页可能出现Belady 异常（页框增多缺页反而增多）
LRU 最近最久未使用淘汰最长时间没被访问的页性能接近 OPT，最常考
Clock 简单时钟循环扫描访问位LRU 的近似实现
缺页率计算：缺页次数/总访问次数。注意：发生缺页不一定淘汰（内存有空位时直接调入）；抖动（颠簸）= 缺页率过高，CPU 大部分时间在换页。

分段 vs 分页

  • 分页：物理划分、固定大小、有内部碎片；分段：逻辑划分、不定长、有外部碎片。便于共享保护的是分段。

第4章 文件管理

  • 文件逻辑结构：顺序文件、索引文件、索引顺序文件。
  • FAT / 索引节点（inode）：显式链接表，常考概念辨析。
  • 物理结构：连续分配（随机访问快、有外部碎片）、链接分配（隐式链接/显式FAT）、索引分配（一个文件一个索引块）。
  • 目录：单级/两级/树形（多级）。路径名、当前目录、工作目录。
  • 文件共享：硬链接（同一 inode）、软链接（符号链接，快捷方式）。
  • 空闲空间管理：空闲表、空闲链、位示图（常考：位示图用二进制位表示磁盘块是否空闲）。

第5章 设备管理

  • I/O 控制方式：程序直接控制（轮询）→ 中断驱动 → DMA → 通道。CPU 干预越来越少（选择题必考排序/辨析）。
  • 缓冲：单缓冲、双缓冲、循环缓冲、缓冲池。缓冲目的：缓和 CPU 与 I/O 速度不匹配、减少中断次数。
  • SPOOLing（假脱机）：用磁盘模拟脱机 I/O，实现虚拟设备（如共享打印机），常考概念题。
  • 设备分配：独占/共享/虚拟设备；逻辑设备表 LUT。
  • 磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间。寻道时间通常是大头。

磁盘调度算法（计算必考）

算法规则
FCFS按请求顺序（磁头来回跑）
SSTF 最短寻道每次找离当前最近的（可能饿死边缘请求）
SCAN 电梯调度沿一个方向扫到头再折返
C-SCAN 循环扫描只在一个方向服务，到头直接跳回起点
考试常给磁道序列，让你按 SSTF/SCAN 算总寻道距离。方法：画一条磁道数轴，逐个标记移动轨迹，最后求和。注意 SCAN 题目会给"当前移动方向"。

第6章 其他高频小考点

中断与异常内中断（异常：除0、越界）vs 外中断（I/O完成、时钟）；系统调用是用户态→核心态的"特殊中断"。
用户态/核心态特权指令只能在核心态执行；系统调用切换到核心态。
管程高级同步机制，封装了共享数据和 PV 操作；同一时刻只有一个进程在管程内。海南自考13180 大纲为"经典内容"，管程可能只考名词解释。
实时调度EDF 最早截止期优先；RM 单调速率。
常用缩写OS/PCB/LRU/FIFO/DMA/SPOOLing/FCFS/SSTF

1. OS 四大特征：并发、共享、虚拟、异步。并发和共享是最基本特征，互为存在条件。
2. OS 四大功能：处理机管理、存储管理、设备管理、文件管理。
3. 进程是资源分配的基本单位，线程是 CPU 调度的基本单位。
4. PCB 是进程存在的唯一标志；进程 = PCB + 程序段 + 数据段。
5. 进程三态：就绪→运行（调度）、运行→阻塞（主动等事件）、阻塞→就绪（被动被唤醒）、运行→就绪（时间片到）。阻塞不能直接运行。
6. P 操作减 1，S<0 阻塞；V 操作加 1，S≤0 唤醒。互斥信号量初值 1，同步信号量初值 = 资源数。
7. 死锁四条件：互斥、占有且等待、不可剥夺、循环等待（缺一不可，破坏一个即可预防）。
8. 死锁处理四策略：预防、避免（银行家算法）、检测、解除。
9. SJF 平均等待时间最短；RR 是分时系统的算法；时间片太大退化为 FCFS。
10. 分页有内部碎片，分段有外部碎片；分段便于共享与保护（逻辑单位），分页是物理单位。
11. 物理地址 = 块号 × 页大小 + 页内偏移；页号 = 逻辑地址 ÷ 页大小。
12. 置换算法：OPT（最优不可实现）、FIFO（有 Belady 异常）、LRU（近似最优，考得最多）。
13. 抖动（颠簸）：缺页率过高导致 CPU 忙于换页。
14. 索引文件引入的目的是加快文件查找速度；inode（索引节点）把文件名与文件描述分开。
15. 硬链接共享同一 inode；软链接（符号链接）是路径的快捷方式。
16. 空闲块管理：位示图用每一位表示一个磁盘块的使用情况。
17. I/O 控制方式演进：轮询 → 中断 → DMA → 通道，CPU 干预依次减少。
18. SPOOLing（假脱机）技术把独占设备改造成共享的虚拟设备（典型：打印机）。
19. 磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间。
20. 磁盘调度：SSTF 最短寻道优先；SCAN 电梯算法（沿方向扫到底再折返）。

答题顺序

  2. 再做简单应用题（页式地址变换、PV 操作、磁盘调度——本页都练过套路）。

各题型保分技巧

  • 选择题：排除法优先，"绝对化措辞"（一定/必须/所有）的选项大概率是错的；"可能/通常/一般来说"的选项大概率是对的。
  • 填空题：实在不会就填本页出现过的关键词（信号量、PCB、抖动、位示图、LRU…），命中率不低。
  • 计算题：必须写步骤。"页号=逻辑地址÷页大小"这种公式哪怕最后算错，写公式也有过程分。卷面整洁，分点作答。
  • 简答题：按"定义 → 特点/组成 → 举例"三段式写，字数宁可超、不要空白。
两条红线：① 不留空白，选择不确定也要蒙（排除后二选一）；② 计算题步骤优先于结果，公式分必拿。
