# 13180《操作系统》两天冲刺

双击 `13180操作系统-两天冲刺.html`，用 Edge / Chrome 打开。文件内嵌全部CSS、JavaScript和题库，断网也能练，不需要安装。

建议顺序：15题摸底 → 对应章节速记 → 五类计算训练 → 简答闭卷默写 → 90分钟自编模拟 → 错题复练。首页有可勾选的两天时间表，时间段可按实际作息平移。

- 64道原创单选，答后解析，按章/随机练习。
- 32张速记卡，支持检索、闭卷回忆、掌握标记和打印。
- 五类自动生成计算题：FCFS/SJF/SRTF/RR调度、分页地址、FIFO/LRU/OPT置换、银行家安全性、FCFS/SSTF/SCAN/LOOK磁盘调度。
- 16道简答，草稿保存、参考要点、自评勾选。
- 自编100分模拟：20单选+4计算+4简答，90分钟；闭页不暂停。计算结果自动判定，过程自行核对；简答手动自评。
- 错题连续两次答对后移出；进度JSON导出与导入。

进度保存于当前浏览器的localStorage。同一文件用不同浏览器、在线预览或不同打开地址，不一定共用进度。建议在“备份与资料”导出JSON；禁用本地存储时也可以练习并手动导出。

内容依据2023年版教材八章目录组织；非完整官方大纲复刻、非真题，不宣称考频或预测成绩。课程信息与出处见页面“备份与资料”。考试时间以个人准考证为准。

开发源：`data.js`（内容）、`engines.js`（算法）、`app.js`（交互）、`style.css`。修改后运行 `node build.cjs` 重新生成单文件。`index.html`与中文名HTML内容相同。
